# 拾影 Photo Fit Picker

一个本地运行的 Windows / macOS 照片初筛工具。它会读取照片的拍摄时间和视觉特征，把连拍、同机位的近似照片整理成组，再由用户逐组确认保留项。

## 下载

前往 [GitHub Releases](https://github.com/Tohsaka-Rin-Ovo/photo-fit-picker/releases) 下载：

- macOS：`PhotoFitPicker-macOS.dmg`

Windows 使用同一套界面和业务代码，安装包将在后续版本提供。

安装包暂未配置商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 可能提示未知开发者。`SHA256SUMS.txt` 可用于核对下载文件是否完整。

没有现成照片也可以点击应用空状态中的“试用演示照片”。内置 11 张演示素材，会形成 3 个近似照片组和 2 张独立照片，用于体验推荐、多选与批量操作。应用会先将素材复制到系统缓存目录，试用移动或回收站操作不会改动安装包内的原始素材。

## 当前功能

- 拖入或选择整个照片文件夹，递归扫描常规图片、HEIC 和主流相机 RAW。
- 根据 EXIF 时间、感知哈希和色彩分布对近似照片分组。
- 读取相机、镜头、快门、光圈、ISO、焦距、GPS，以及部分 Nikon MakerNote 参数。
- 以清晰度和曝光为依据标出每组最佳照片，但不会自动移动。
- 支持单张保留/排除、本组全部保留/排除，以及一键保留最佳并进入下一组。
- 照片卡片显示日期、尺寸、格式和大小；点击后可在大图信息栏查看相机、镜头、拍摄参数、GPS、质量判断与推荐原因。
- 每张照片可独立勾选，选择状态可跨照片组保留。
- 底部批量栏支持将所选照片标为保留/排除、移动到指定文件夹或移到系统回收站。
- `Ctrl+A` / `Command+A` 选择当前照片组，`Esc` 清空所有选择。
- 将确认保留的原文件移动到自定义文件夹；遇到同名文件自动改名，不覆盖。
- RAW、同名 JPEG 和 XMP sidecar 会作为关联资产共同移动，避免拆散素材。
- 所有移动使用批次事务：中途失败会自动回滚；保存移动前状态，并支持撤销最近一次批量移动或整理。
- 左下角设置会进入独立的全窗口设置工作区，可切换明亮/深色外观、减少动画，并管理文件夹、整理和算法参数。
- 筛选提供保守、均衡、宽松和自定义预设；算法页可调色彩及推荐权重，实验页可切换差异/均值哈希与跨日期完全重复识别。
- “整理”会先按拍摄日、活动间隔和 GPS 距离生成本地预览；可在全窗口工作区中改名、合并分组或拆分所选照片。
- “排除”只记录审核状态，不删除文件；程序不会自动删除任何照片。
- 用户可在大图预览中逐张选择“移到回收站”，每次必须经过确认弹窗，并由系统回收站保留恢复能力。
- 所有分析在电脑本地完成，不上传照片。

## 图片格式

常规格式包括 JPG、JPEG、PNG、WebP、BMP、TIFF、HEIC 和 HEIF。

RAW 通过 LibRaw/rawpy 读取，目前纳入扫描的格式包括 Canon CR2/CR3/CRW、Nikon NEF/NRW、Sony ARW/SR2/SRF、Fujifilm RAF、Adobe DNG、Panasonic RW2/RWL、Olympus ORF/ORI、Pentax PEF/PTX、Samsung SRW、Sigma X3F，以及 3FR、DCR、ERF、FFF、GPR、IIQ、KDC、MEF、MOS、MRW、R3D 等格式。

ExifRead 会直接从常规图片和多数 RAW 容器读取标准拍摄参数；Nikon 文件还会尽可能提取对焦模式、拍摄模式、防抖和 Picture Control 等 MakerNote 信息。不同机型写入的私有字段并不完全一致，无法识别时只留空，不会阻止照片导入。

程序优先使用 RAW 内嵌预览图进行快速分析；没有预览图时才进行半尺寸显影。移动、撤销和回收站操作针对完整 RAW 原文件，不会把预览图写回原文件。新相机或厂商特殊 RAW 变体能否读取取决于安装包所带的 LibRaw 版本。

## 运行源码

需要 Python 3.9 或更高版本。

```bash
python3 -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
python -m pip install -e .
python -m photo_fit_picker.main
```

## 使用流程

1. 选择或拖入照片文件夹。
2. 应用会使用默认的 84% 相似度和 90 秒时间范围自动分析；需要调整时打开左下角“设置”的“筛选”页面重新分析。
3. 在左侧逐组查看照片；“最佳”表示组内清晰度和曝光综合得分最高。
4. 点击“保留最佳并继续”可完成当前组并自动进入下一组，也可单独保留、排除或批量选择照片。
5. 在“设置 > 文件夹”中选择默认目标位置，点击顶部按钮移动所有已保留照片；如需恢复，可点击返回箭头撤销。

左下角“整理”会基于当前批次生成建议文件夹。默认把超过 180 分钟的拍摄间隔视为新活动，并将相距超过 2 km 的 GPS 位置分开；这些值可在“设置 > 整理”中修改。预览不会联网查询地名，也不会在最终确认前创建目录或移动文件。执行前会列出照片、关联文件和目标位置，取消确认不会产生任何文件操作。

在大图预览中点击回收站图标会出现确认弹窗。只有用户明确确认后，该张照片才会进入系统废纸篓/回收站；程序不提供永久删除或自动删除功能。

批量移到回收站同样必须经过确认弹窗。批量移动只处理明确勾选的照片，不会顺带移动其他已保留或已排除的照片。

相似度越高，分组越严格；误把不同画面放在一起时可使用“保守”，连拍没有聚到一起时可使用“宽松”。完全重复识别只会把字节内容一致的文件归组，不会自行删除副本。移动前请保留独立备份，尤其是在第一次处理重要照片时。

## 打包

macOS：

```bash
chmod +x scripts/build-macos.sh
./scripts/build-macos.sh
```

完成后可在 `dist/release/PhotoFitPicker-macOS.dmg` 找到安装包。

Windows：双击 `scripts\build-windows.bat`，或在命令提示符中运行它。

GitHub Actions 配置位于 `.github/workflows/build.yml`。手动运行工作流会生成临时构建产物；推送 `v*` 标签会自动创建 GitHub Release，上传 Windows 安装程序、macOS DMG 和 SHA-256 校验文件。PyInstaller 必须在目标操作系统上构建，因此不能只在 Mac 上直接生成可靠的 Windows 程序。

## 第一版算法边界

当前算法适合连拍、同机位轻微变化、人物表情不同等近似画面，并可识别字节完全相同的副本。它不做人物身份识别，也不会理解“这张构图更有故事感”。后续可增加人脸闭眼检测、截图检测和可选的本地语义聚类。

当前整理建议已利用拍摄时间、GPS 和相机信息；后续还可读取 XMP/IPTC 标签，并在明确联网授权后把坐标转换成地点名称。完整的阶段计划和照片安全边界见 [ROADMAP.md](ROADMAP.md)。
